# 事件枚举

*事件系统是框架的神经系统，而 EventType 就是这个系统的「信号编码」。*

EventEnums 定义了框架中使用的事件类型枚举，是事件中心（EventMgr）的基础。

## 核心概念

EventType 是一个枚举类型，用于标识不同的事件：

```csharp
public enum EventType
{
    BaseEvent,
    Move
}
```

每个枚举值代表一种特定的事件类型，用于事件的订阅和触发。

## 使用方法

**定义新事件**

在 EventEnums.cs 中添加新的事件类型：

```csharp
public enum EventType
{
    BaseEvent,
    Move,

    // 游戏系统事件
    GameStart,
    GamePause,
    GameResume,
    GameOver,

    // 玩家相关事件
    PlayerHPChange,
    PlayerMPChange,
    PlayerLevelUp,
    PlayerDie,

    // 输入事件
    Jump,
    Fire,
    Skill1,
    Skill2,

    // UI 事件
    OpenMenu,
    CloseMenu,
    ShowDialog,
    HideDialog,

    // 场景事件
    SceneLoadStart,
    SceneLoadComplete,

    // 自定义事件...
    MyCustomEvent
}
```

**订阅事件**

```csharp
void Start()
{
    // 订阅玩家血量变化事件
    EventMgr.Instance.AddEventListener<int>(EventType.PlayerHPChange, OnHPChange);

    // 订阅游戏开始事件
    EventMgr.Instance.AddEventListener(EventType.GameStart, OnGameStart);
}

void OnHPChange(int hp)
{
    Debug.Log($"当前血量: {hp}");
}

void OnGameStart()
{
    Debug.Log("游戏开始！");
}
```

**触发事件**

```csharp
void TakeDamage(int damage)
{
    hp -= damage;
    // 触发血量变化事件
    EventMgr.Instance.EventTrigger(EventType.PlayerHPChange, hp);

    if (hp <= 0)
    {
        // 触发玩家死亡事件
        EventMgr.Instance.EventTrigger(EventType.PlayerDie);
    }
}
```

## 事件命名规范

为了保持代码的可读性和可维护性，建议遵循以下命名规范：

**1. 使用有意义的名称**

```csharp
// 好的命名
PlayerHPChange,
EnemySpawn,
ItemPickup

// 不好的命名
Event1,
Event2,
DoSomething
```

**2. 使用动词+名词的结构**

```csharp
// 状态变化
PlayerHPChange,     // 玩家血量变化
EnemySpawn,         // 敌人生成
ItemPickup,         // 物品拾取

// 动作指令
Jump,               // 跳跃
Fire,               // 开火
OpenMenu,           // 打开菜单
```

**3. 按模块分组**

```csharp
public enum EventType
{
    //========== 框架事件 ==========
    BaseEvent,

    //========== 输入事件 ==========
    Move,
    Jump,
    Fire,

    //========== 游戏系统事件 ==========
    GameStart,
    GamePause,
    GameOver,

    //========== 玩家事件 ==========
    PlayerHPChange,
    PlayerMPChange,
    PlayerLevelUp,
    PlayerDie,

    //========== 敌人事件 ==========
    EnemySpawn,
    EnemyDie,
    EnemyAlert,

    //========== UI 事件 ==========
    OpenMenu,
    CloseMenu,
    ShowDialog,
    HideDialog,
    ButtonClick,

    //========== 场景事件 ==========
    SceneLoadStart,
    SceneLoadComplete,
    SceneUnload
}
```

**4. 避免过于具体的名称**

```csharp
// 过于具体，复用性差
PlayerRedPotionPickup,

// 更通用的命名
ItemPickup,  // 通过参数传递物品类型
```

## 事件参数设计

事件可以带参数，参数的设计也很重要：

**简单事件（无参数）**

```csharp
// 不需要额外信息的事件
EventMgr.Instance.EventTrigger(EventType.GameStart);
EventMgr.Instance.EventTrigger(EventType.Jump);
```

**带一个参数**

```csharp
// 血量变化，只需要传递当前血量
EventMgr.Instance.EventTrigger(EventType.PlayerHPChange, currentHP);

// 场景加载完成，传递场景名称
EventMgr.Instance.EventTrigger(EventType.SceneLoadComplete, "Level2");
```

**带多个参数**

如果需要传递多个参数，使用类或结构体封装：

```csharp
public struct DamageInfo
{
    public int Damage;
    public Vector3 HitPosition;
    public GameObject Attacker;
}

// 触发事件
DamageInfo info = new DamageInfo
{
    Damage = 100,
    HitPosition = transform.position,
    Attacker = player
};
EventMgr.Instance.EventTrigger(EventType.TakeDamage, info);
```

## 注意事项

1. **事件类型是框架的基础**，修改已有事件类型会影响所有订阅者，需要谨慎

2. **保持向后兼容**，新增事件类型不会影响现有代码

3. **避免事件泛滥**，不是所有通信都需要通过事件中心，过度使用会增加调试难度

4. **文档化你的事件**，大型项目中建议维护一个事件文档，说明每个事件的用途和参数
