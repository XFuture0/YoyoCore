<b><size=20>音频管理器</size></b>

<i>游戏的灵魂一半在画面，一半在声音。AudioMgr 就是来管那「一半灵魂」的。</i>

AudioMgr 提供了背景音乐和音效的统一管理，支持音量控制、暂停/恢复等功能。

<b><size=16>诞生背景</size></b>

Unity 的 AudioSource 虽然功能强大，但在实际项目中直接使用会有一些问题：

1. <b>背景音乐和音效混在一起</b>：难以独立控制
2. <b>音量管理分散</b>：每个 AudioSource 都要单独设置
3. <b>音效对象管理混乱</b>：播放完的音效 AudioSource 需要手动清理

AudioMgr 通过分层管理解决了这些问题。

<b><size=16>核心概念</size></b>

AudioMgr 将音频分为两类：

<b>类型：背景音乐（BGM）</b>
用途：场景氛围音乐
特点：同时只播放一首，循环播放

<b>类型：音效（Sound）</b>
用途：按钮点击、爆炸、射击等
特点：可同时播放多个，播放完自动清理

<b><size=16>使用方法</size></b>

<b>背景音乐</b>

// 播放背景音乐
AudioMgr.Instance.PlayerBackMusic("MainTheme");

// 暂停背景音乐
AudioMgr.Instance.PauseBackMusic();

// 停止背景音乐
AudioMgr.Instance.StopBackMusic();

// 调整背景音乐音量（0~1）
AudioMgr.Instance.ChangeBackMusicVolume(0.5f);

// 清理背景音乐
AudioMgr.Instance.ClearBackMusic();

<b>音效</b>

// 播放音效
AudioMgr.Instance.PlaySound("Explosion");

// 播放循环音效
AudioMgr.Instance.PlaySound("Engine", true);

// 播放音效并获取 AudioSource 引用
AudioMgr.Instance.PlaySound("GunShot", false, (source) =>
{
    // 可以对 source 进行额外设置
    source.pitch = Random.Range(0.9f, 1.1f);
});

// 停止特定音效
AudioMgr.Instance.StopSound(audioSource);

// 调整音效音量
AudioMgr.Instance.ChangeSoundVolume(0.8f);

// 暂停/恢复所有音效
AudioMgr.Instance.PauseSound(false);  // 暂停
AudioMgr.Instance.PauseSound(true);   // 恢复

// 清理所有音效
AudioMgr.Instance.ClearSound();

<b><size=16>完整示例</size></b>

public class GameAudio : MonoBehaviour
{
    void Start()
    {
        // 播放背景音乐
        AudioMgr.Instance.PlayerBackMusic("BattleBGM");
        AudioMgr.Instance.ChangeBackMusicVolume(0.3f);
    }

    void OnPlayerShoot()
    {
        // 播放射击音效
        AudioMgr.Instance.PlaySound("Shoot");
    }

    void OnEnemyExplode()
    {
        // 播放爆炸音效，随机音调
        AudioMgr.Instance.PlaySound("Explosion", false, (source) =>
        {
            source.pitch = Random.Range(0.8f, 1.2f);
        });
    }

    void OnGamePause()
    {
        // 暂停背景音乐和音效
        AudioMgr.Instance.PauseBackMusic();
        AudioMgr.Instance.PauseSound(false);
    }

    void OnGameResume()
    {
        // 恢复
        AudioMgr.Instance.PlayerBackMusic("BattleBGM");
        AudioMgr.Instance.PauseSound(true);
    }
}

<b><size=16>技术细节</size></b>

<b>背景音乐实现</b>

背景音乐使用一个专门的 AudioSource：

if (BackMusic == null)
{
    GameObject obj = new GameObject("BackMusic");
    GameObject.DontDestroyOnLoad(obj);
    BackMusic = obj.AddComponent&lt;AudioSource&gt;();
}
BackMusic.clip = Resources.Load&lt;AudioClip&gt;("Music/" + name);
BackMusic.loop = true;
BackMusic.Play();

<b>音效自动清理</b>

音效在 Update 中自动清理已播放完成的 AudioSource。

<b><size=16>注意事项</size></b>

<b>1. 音频文件路径</b>

音频文件需要放在 <b>Resources/Music/</b> 目录下。

<b>2. 音频格式选择</b>

<b>格式：MP3</b>
适用场景：背景音乐
说明：压缩率高，适合长音频

<b>格式：WAV</b>
适用场景：音效
说明：无压缩，适合短音频

<b>格式：OGG</b>
适用场景：通用
说明：开源格式，压缩率好

<b>3. 性能考虑</b>

- 背景音乐使用一个 AudioSource 即可
- 音效使用多个 AudioSource，但数量不宜过多（建议同时播放不超过 10 个）

<b><size=16>技术地位和意义</size></b>

AudioMgr 是框架中负责「听觉体验」的组件。它将音频管理从业务逻辑中抽离，让开发者可以方便地控制游戏的「另一半灵魂」。

<i>好的音效能让玩家更有沉浸感，而好的音频管理能让开发者更专注于创造这些音效。</i>
