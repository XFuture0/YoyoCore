<b><size=20>代码耗时检测工具</size></b>

<i>优化代码之前，你得先知道哪里慢。CustomTimerTool 就是那个告诉你「哪里慢」的工具。</i>

CustomTimerTool 提供了一个简单的代码段耗时测量功能，基于 IDisposable 接口实现，使用非常方便。

<b><size=16>诞生背景</size></b>

性能优化是游戏开发中永恒的话题。但在优化之前，我们需要知道：

<size=13>1. 哪段代码是性能瓶颈？
2. 优化后到底快了多少？</size>

传统的计时方式：

float startTime = Time.realtimeSinceStartup;

// 要测量的代码
DoSomething();

float endTime = Time.realtimeSinceStartup;
Debug.Log($"耗时: {(endTime - startTime) * 1000}ms");

这种方式的问题是：
<size=13>- 代码侵入性强
- 如果有多个 return 分支，计时逻辑会很复杂
- 忘记写结束计时会导致错误</size>

CustomTimerTool 使用 using 语句和 IDisposable，让计时更加优雅。

<b><size=16>核心功能</size></b>

<b>基本使用</b>

using (new CustomTimerTool("某操作"))
{
    // 要测量的代码
    DoSomething();
}
// 离开 using 块时自动输出耗时

控制台输出：
<size=13>某操作: 15.23ms</size>

<b><size=16>技术实现</size></b>

public class CustomTimerTool : IDisposable
{
    private string Name;
    private float StartTime;

    public CustomTimerTool(string name)
    {
        Name = name;
        StartTime = Time.realtimeSinceStartup;
    }

    public void Dispose()
    {
        float spendTime = (Time.realtimeSinceStartup - StartTime) * 1000f;
        Debug.Log(Name + ": " + spendTime + "ms");
    }
}

<b>使用真实时间</b>

工具使用 <b>Time.realtimeSinceStartup</b> 而不是 <b>Time.time</b>，这意味着：
<size=13>- 不受 Time.timeScale 影响
- 即使游戏暂停，计时也是准确的</size>

<b><size=16>注意事项</size></b>

<size=13><b>1. 只在 Debug 模式使用</b>

发布版本中应该移除计时代码：

#if UNITY_EDITOR
    using (new CustomTimerTool("操作"))
#endif
    {
        DoSomething();
    }

<b>2. 精度限制</b>

Time.realtimeSinceStartup 的精度取决于平台，通常在毫秒级别。对于需要微秒级精度的测量，需要使用 System.Diagnostics.Stopwatch。

<b>3. GC 开销</b>

创建 CustomTimerTool 对象会有少量 GC 开销，对于极高频率的调用（如每帧调用数千次），建议使用条件编译在发布版本中完全移除。

<b>4. 异步代码</b>

对于异步代码，using 语句可能不太适用：

// 这种用法会有问题
async void SomeAsyncFunction()
{
    using (new CustomTimerTool("异步操作"))
    {
        await Task.Delay(1000);  // 计时会在 await 处结束！
    }
}

异步代码建议手动计时：

async void SomeAsyncFunction()
{
    float start = Time.realtimeSinceStartup;
    await Task.Delay(1000);
    float elapsed = (Time.realtimeSinceStartup - start) * 1000f;
    Debug.Log($"异步操作: {elapsed}ms");
}</c></size>

<b><size=16>扩展：更精确的计时器</size></b>

如果需要更高精度，可以使用 Stopwatch：

public class PreciseTimer : IDisposable
{
    private string Name;
    private Stopwatch Stopwatch;

    public PreciseTimer(string name)
    {
        Name = name;
        Stopwatch = Stopwatch.StartNew();
    }

    public void Dispose()
    {
        Stopwatch.Stop();
        Debug.Log($"{Name}: {Stopwatch.ElapsedMilliseconds}ms ({Stopwatch.ElapsedTicks} ticks)");
    }
}
