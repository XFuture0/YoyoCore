<b><size=20>计时器管理器</size></b>

<i>协程写多了，总会想有个更简洁的方式来处理延时任务。TimerMgr 就是那个「更简洁的方式」。</i>

TimerMgr 提供了一套基于 ID 的计时器系统，支持普通计时和真实时间计时，可以方便地创建、控制和管理计时器。

<b><size=16>诞生背景</size></b>

在 Unity 中处理延时任务，通常有两种方式：

<b>方式1：协程</b>

IEnumerator DelayAction()
{
    yield return new WaitForSeconds(2f);
    DoSomething();
}

<b>方式2：Update 计时</b>

float timer = 0;
void Update()
{
    timer += Time.deltaTime;
    if (timer >= 2f)
    {
        DoSomething();
        enabled = false;
    }
}

这两种方式都有局限性：
- 协程分散在各处，难以统一管理
- Update 计时需要手动管理状态
- 难以在运行时暂停/恢复/取消计时器

TimerMgr 提供了一个集中式的计时器管理方案。

<b><size=16>核心概念</size></b>

TimerMgr 使用 TimeItem 来描述一个计时器：

public class TimeItem
{
    public int KeyID;           // 计时器唯一 ID
    public UnityAction overcallback;  // 计时结束回调
    public UnityAction callback;      // 间隔回调
    public float allTime;       // 剩余总时间
    public float MaxAllTime;    // 总时间
    public float intervalTime;  // 间隔剩余时间
    public float MaxIntervalTime; // 间隔时间
    public bool isRunning;      // 是否运行中
}

<b><size=16>使用方法</size></b>

<b>启动计时器系统</b>

// 在程序开始时启动
TimerMgr.Instance.Start();

<b>创建计时器</b>

// 创建一个 5 秒后触发的计时器
int timerId = TimerMgr.Instance.CreateTimer(
    false,              // 是否使用真实时间
    5f,                 // 总时间
    0,                  // 间隔时间（0 表示不触发间隔回调）
    null,               // 间隔回调
    () => Debug.Log("计时结束！")  // 结束回调
);

<b>控制计时器</b>

// 启动计时器
TimerMgr.Instance.StartTimer(timerId);

// 暂停计时器
TimerMgr.Instance.StopTimer(timerId);

// 重置计时器
TimerMgr.Instance.ReSetTimer(timerId);

// 移除计时器
TimerMgr.Instance.RemoveTimer(timerId);

// 查询剩余时间
float remainingTime = TimerMgr.Instance.CheckTimer(timerId);

<b>停止计时器系统</b>

TimerMgr.Instance.Stop();

<b><size=16>完整示例</size></b>

<b>延时执行</b>

public class Example : MonoBehaviour
{
    void Start()
    {
        TimerMgr.Instance.Start();

        // 3 秒后执行
        TimerMgr.Instance.CreateTimer(false, 3f, 0, null, () =>
        {
            Debug.Log("3 秒到了！");
        });
    }
}

<b>定时重复执行</b>

void Start()
{
    TimerMgr.Instance.Start();

    // 每 1 秒执行一次，总共执行 5 秒
    int timerId = TimerMgr.Instance.CreateTimer(
        false,
        5f,     // 总时间 5 秒
        1f,     // 每 1 秒触发一次
        () => Debug.Log("滴答..."),  // 间隔回调
        () => Debug.Log("计时结束！")  // 结束回调
    );

    TimerMgr.Instance.StartTimer(timerId);
}

<b>真实时间计时（不受游戏暂停影响）</b>

// 创建一个真实时间计时器，即使游戏暂停也会继续计时
int realTimerId = TimerMgr.Instance.CreateTimer(
    true,   // 使用真实时间
    60f,    // 60 秒
    0,
    null,
    () => Debug.Log("一分钟到了！")
);

<b><size=16>技术细节</size></b>

<b>双计时器系统</b>

TimerMgr 同时维护两套计时器：
- 普通计时器（受时间缩放影响）
- 真实时间计时器（不受时间缩放影响）

<b>计时精度</b>

计时器的更新间隔由 Setting.IntervalTime 控制，默认是 0.05 秒（20 FPS）。

<b><size=16>注意事项</size></b>

<b>1. 必须先 Start</b>

使用计时器前必须先调用 TimerMgr.Instance.Start()，否则计时器不会更新。

<b>2. 记得清理</b>

计时器在触发结束后会自动从字典中移除，但如果手动停止计时器，记得清理。

<b>3. 真实时间 vs 普通时间</b>

<b>特性：受 Time.timeScale 影响</b>
普通计时器：是
真实时间计时器：否

<b>特性：游戏暂停时</b>
普通计时器：暂停
真实时间计时器：继续

<b>特性：适用场景</b>
普通计时器：游戏内技能 CD、BUFF 持续时间
真实时间计时器：每日奖励、现实倒计时

<b><size=16>与协程的对比</size></b>

<b>特性：代码可读性</b>
TimerMgr：高（集中管理）
协程：中（分散在各处）

<b>特性：运行时控制</b>
TimerMgr：方便（通过 ID）
协程：需要保存 IEnumerator

<b>特性：暂停/恢复</b>
TimerMgr：支持
协程：需要额外处理

<b><size=16>技术地位和意义</size></b>

TimerMgr 是框架中负责「时间管理」的组件。它将分散的延时任务集中管理，提供了更灵活的控制方式。

<i>如果说协程是「一次性」的延时，那 TimerMgr 就是「可管理」的延时。</i>
