# 输入管理器

*处理输入这件事，说简单也简单，说复杂……咳咳，等你需要支持手柄、触屏、键盘的时候就知道复杂了。*

InputMgr 提供了一个统一的输入管理方案，将输入检测与事件系统结合，让输入处理变得更加优雅。

## 诞生背景

传统的 Unity 输入处理通常是这样的：

```csharp
void Update()
{
    if (Input.GetKeyDown(KeyCode.Space))
    {
        Jump();
    }
    if (Input.GetKeyDown(KeyCode.Escape))
    {
        Pause();
    }
    // ... 更多的输入检测
}
```

这种方式的问题是：
1. 输入检测散落在各个类的 Update 中，难以统一管理
2. 键位硬编码，修改键位需要改代码
3. 无法方便地启用/禁用输入
4. 输入逻辑和业务逻辑耦合

InputMgr 通过「事件绑定」的方式解决了这些问题。

## 核心概念

InputMgr 使用 InputInfo 类来描述一个输入配置：

```csharp
public class InputInfo
{
    public E_KeyOrMouse KeyOrMouse;  // 键盘还是鼠标
    public E_InputType InputType;    // 按下、抬起还是持续按下
    public KeyCode KeyCode;          // 按键代码
    public int MouseCode;            // 鼠标按钮代码
}
```

输入类型（E_InputType）：

**类型：Down**
说明：按键按下的瞬间触发一次

**类型：Up**
说明：按键抬起的瞬间触发一次

**类型：Press**
说明：按键持续按下时每帧都触发

## 使用方法

**绑定键盘输入**

```csharp
// 绑定空格键按下事件
InputMgr.Instance.AddKeyBoardInfo(
    EventType.Jump,           // 事件类型
    KeyCode.Space,            // 按键
    InputInfo.E_InputType.Down, // 触发时机
    Jump                      // 回调函数
);

void Jump()
{
    Debug.Log("跳跃！");
}
```

**绑定鼠标输入**

```csharp
// 绑定鼠标左键按下事件
InputMgr.Instance.AddMouseInfo(
    EventType.Fire,
    0,                        // 0=左键, 1=右键, 2=中键
    InputInfo.E_InputType.Down,
    Fire
);

void Fire()
{
    Debug.Log("开火！");
}
```

**移除输入绑定**

```csharp
InputMgr.Instance.RemoveInputInfo(EventType.Jump);
```

**启用/禁用输入**

```csharp
// 关闭输入检测
InputMgr.Instance.StartOrCloseInput(false);

// 开启输入检测
InputMgr.Instance.StartOrCloseInput(true);
```

## 完整示例

```csharp
public class PlayerController : MonoBehaviour
{
    void Start()
    {
        // 绑定移动输入
        InputMgr.Instance.AddKeyBoardInfo(
            EventType.MoveLeft,
            KeyCode.A,
            InputInfo.E_InputType.Press,
            () => Move(Vector3.left)
        );

        InputMgr.Instance.AddKeyBoardInfo(
            EventType.MoveRight,
            KeyCode.D,
            InputInfo.E_InputType.Press,
            () => Move(Vector3.right)
        );

        // 绑定跳跃输入
        InputMgr.Instance.AddKeyBoardInfo(
            EventType.Jump,
            KeyCode.Space,
            InputInfo.E_InputType.Down,
            Jump
        );

        // 绑定攻击输入
        InputMgr.Instance.AddMouseInfo(
            EventType.Attack,
            0,
            InputInfo.E_InputType.Down,
            Attack
        );
    }

    void OnDestroy()
    {
        // 清理输入绑定
        InputMgr.Instance.RemoveInputInfo(EventType.MoveLeft);
        InputMgr.Instance.RemoveInputInfo(EventType.MoveRight);
        InputMgr.Instance.RemoveInputInfo(EventType.Jump);
        InputMgr.Instance.RemoveInputInfo(EventType.Attack);
    }

    void Move(Vector3 dir)
    {
        transform.position += dir * Time.deltaTime * speed;
    }

    void Jump()
    {
        rb.AddForce(Vector3.up * jumpForce);
    }

    void Attack()
    {
        // 攻击逻辑
    }
}
```

## 技术实现

InputMgr 在构造函数中订阅了 MonoMgr 的 Update：

```csharp
private InputMgr()
{
    MonoMgr.Instance.AddUpdateListener(Update);
}
```

在 Update 中轮询所有绑定的输入。

## 注意事项

**1. 事件定义**

所有输入都会触发 EventType 对应的事件，所以你需要先在 EventEnums.cs 中定义好相关事件。

**2. 输入冲突**

同一个 EventType 只能绑定一个输入配置。如果重复绑定，后面的会覆盖前面的。

**3. 清理绑定**

记得在对象销毁时清理输入绑定，否则会造成内存泄漏。
