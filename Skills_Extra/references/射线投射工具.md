# 射线投射工具

*UI 和 3D 世界的交互，往往就靠一条射线来连接。*

RayCastTool 专门处理 UI 相关的射线检测，提供了获取单个组件和获取所有组件的功能。

## 诞生背景

Unity 的 UI 射线检测和 3D 射线检测使用不同的系统：

**3D 射线检测**：

```csharp
Physics.Raycast(ray, out hit);
```

**UI 射线检测**：

```csharp
PointerEventData pointerEventData = new PointerEventData(EventSystem.current);
pointerEventData.position = Input.mousePosition;
List<RaycastResult> results = new List<RaycastResult>();
EventSystem.current.RaycastAll(pointerEventData, results);
```

UI 射线检测的代码相对繁琐，RayCastTool 对其进行了封装，让 UI 交互检测更加简洁。

## 核心功能

**获取单个 UI 组件**

根据位置获取指定名称或标签的第一个 UI 组件：

```csharp
// 通过名称获取 Button
Button btn = RayCastTool.RayCastUIComponent<Button>(
    Input.mousePosition,
    "ConfirmButton",
    false  // false = 按名称查找
);

if (btn != null)
{
    btn.onClick.Invoke();
}
```

**获取所有 UI 组件**

获取某位置下的所有指定类型的 UI 组件：

```csharp
List<Image> images = RayCastTool.RayCastUIComponents<Image>(Input.mousePosition);

foreach (var img in images)
{
    Debug.Log($"检测到 Image: {img.name}");
}
```

## 使用方法

**点击检测**

```csharp
void Update()
{
    if (Input.GetMouseButtonDown(0))
    {
        // 检测是否点击了按钮
        Button btn = RayCastTool.RayCastUIComponent<Button>(
            Input.mousePosition,
            "",
            false
        );

        if (btn != null)
        {
            Debug.Log($"点击了按钮: {btn.name}");
        }
    }
}
```

**拖拽检测**

```csharp
public void OnDrag(PointerEventData eventData)
{
    // 检测拖拽目标
    IDropHandler dropTarget = RayCastTool.RayCastUIComponent<IDropHandler>(
        eventData.position,
        "DropZone",
        false
    );

    if (dropTarget != null)
    {
        // 处理放置逻辑
    }

```

**悬浮提示**

```csharp
void Update()
{
    // 检测鼠标下的物品槽
    ItemSlot slot = RayCastTool.RayCastUIComponent<ItemSlot>(
        Input.mousePosition,
        "",
        false
    );

    if (slot != null && slot != lastSlot)
    {
        ShowTooltip(slot.itemData);
        lastSlot = slot;
    }
}
```

**按标签查找**

```csharp
// 获取标签为 "Interactable" 的第一个按钮

    Input.mousePosition,

```

## 完整示例

**自定义点击处理**

```csharp
public class CustomClickHandler : MonoBehaviour
{
    void Update()
    {
        if (Input.GetMouseButtonDown(0))
        {
            HandleClick(Input.mousePosition);
        }
    }

    void HandleClick(Vector2 position)
    {
        // 尝试获取不同类型的组件
        Button btn = RayCastTool.RayCastUIComponent<Button>(position, "", false);
        if (btn != null)
        {
            btn.onClick.Invoke();
            return;
        }

        Toggle toggle = RayCastTool.RayCastUIComponent<Toggle>(position, "", false);
        if (toggle != null)
        {
            toggle.isOn = !toggle.isOn;
            return;
        }

        Slider slider = RayCastTool.RayCastUIComponent<Slider>(position, "", false);
        if (slider != null)
        {
            // 计算点击位置对应的值
            RectTransform rect = slider.GetComponent<RectTransform>();
            float normalized = (position.x - rect.position.x) / rect.sizeDelta.x;
            slider.value = Mathf.Lerp(slider.minValue, slider.maxValue, normalized);
        }
    }
}
```

**多层级 UI 检测**

```csharp
void Update()
{
    // 获取鼠标下的所有 Image
    List<Image> images = RayCastTool.RayCastUIComponents<Image>(Input.mousePosition);

    // 按层级排序（通常列表已经是按层级排序的）
    foreach (var img in images)
    {
        Debug.Log($"检测到: {img.name}, 层级: {img.transform.GetSiblingIndex()}");
    }
}
```

## 技术细节

**射线检测实现**

```csharp
public static T RayCastUIComponent<T>(Vector3 position, string name, bool isTag = false) where T : UIBehaviour
{
    List<RaycastResult> raycastResults = new List<RaycastResult>();
    PointerEventData pointerEventData = new PointerEventData(EventSystem.current);
    pointerEventData.position = position;
    EventSystem.current.RaycastAll(pointerEventData, raycastResults);

    if (raycastResults.Count == 0) return null;

    foreach (RaycastResult raycastResult in raycastResults)
    {
        if (isTag)
        {
            if (raycastResult.gameObject.tag == name &&
                raycastResult.gameObject.TryGetComponent<T>(out _))
            {
                return raycastResult.gameObject.GetComponent<T>();
            }
        }
        else
        {
            if (raycastResult.gameObject.name == name &&
                raycastResult.gameObject.TryGetComponent<T>(out _))
            {
                return raycastResult.gameObject.GetComponent<T>();
            }
        }
    }
    return null;
}
```

## 注意事项

1. **需要 EventSystem**：UI 射线检测需要场景中有 EventSystem 对象

2. **Raycast Target**：UI 元素需要勾选 Raycast Target 才能被检测到

3. **层级顺序**：RaycastAll 返回的结果是按层级从前往后排序的

4. **性能考虑**：频繁的射线检测会有性能开销，不要在 Update 中无限制地调用
