# 场景切换

*场景切换看似简单，但要做个好用的封装，还是需要考虑不少细节的。*

SceneChangeMgr 提供了同步和异步两种场景加载方式，并支持加载完成后的回调。

## 诞生背景

Unity 原生的场景切换 API 是 SceneManager，但直接使用有一些不便：

```csharp
// 同步加载 - 会卡顿
SceneManager.LoadScene("Level2");

// 异步加载 - 需要自行处理协程
AsyncOperation ao = SceneManager.LoadSceneAsync("Level2");
while (!ao.isDone)
{
    // 更新进度条
}
```

SceneChangeMgr 封装了这些操作，提供了更简洁的 API。

## 核心功能

**同步加载**

```csharp
SceneChangeMgr.Instance.LoadScene("Level2");
```

同步加载会阻塞主线程直到场景加载完成。适用于：
- 加载时间很短的场景
- 初始加载/重启游戏
- 不需要进度显示的场景

**异步加载**

```csharp
SceneChangeMgr.Instance.LoadSceneAsync("Level2", () =>
{
    Debug.Log("场景加载完成！");
});
```

异步加载不会阻塞主线程，适用于：
- 加载时间较长的场景
- 需要显示加载界面的场景
- 运行时动态加载

## 使用方法

**基本场景切换**

```csharp
public class GameManager : MonoBehaviour
{
    public void GoToLevel(int levelIndex)
    {
        string sceneName = $"Level{levelIndex}";
        SceneChangeMgr.Instance.LoadSceneAsync(sceneName, OnLevelLoaded);
    }

    void OnLevelLoaded()
    {
        // 场景加载完成后的初始化
        Debug.Log("新场景已加载");
    }
}
```

**带加载界面的场景切换**

```csharp
public class SceneLoader : MonoBehaviour
{
    public GameObject loadingPanel;
    public Slider progressBar;

    public void LoadSceneWithLoading(string sceneName)
    {
        loadingPanel.SetActive(true);
        StartCoroutine(DoLoad(sceneName));
    }

    IEnumerator DoLoad(string sceneName)
    {
        AsyncOperation ao = SceneManager.LoadSceneAsync(sceneName);
        ao.allowSceneActivation = false;  // 加载完成后不自动切换

        while (ao.progress < 0.9f)
        {
            progressBar.value = ao.progress;
            yield return null;
        }

        progressBar.value = 1f;
        yield return new WaitForSeconds(0.5f);  // 稍作停顿

        ao.allowSceneActivation = true;  // 允许切换场景
    }
}
```

## 技术细节

**异步加载的实现**

```csharp
public void LoadSceneAsync(string sceneName, UnityAction callback = null)
{
    MonoMgr.Instance.StartCoroutine(ReallyLoadSceneAsync(sceneName, callback));
}
```

**场景加载进度**

AsyncOperation 的 progress 属性：
- 0 ~ 0.9：加载中
- 0.9：加载完成，等待 allowSceneActivation
- 1.0：场景已激活

```csharp
// 显示真实进度
float progress = Mathf.Clamp01(ao.progress / 0.9f);
progressBar.value = progress;
```

## 注意事项

**1. 场景必须添加到 Build Settings**

要加载的场景必须在 **File > Build Settings > Scenes In Build** 中添加，否则会报错。

**2. 场景切换时的数据保存**

场景切换时，DontDestroyOnLoad 的对象会被保留，其他对象会被销毁。需要持久化的数据应该使用 PlayerPrefs 或静态类保存。

**3. 异步加载的陷阱**

AsyncOperation 加载到 0.9 时会停止，需要设置 allowSceneActivation = true 才能继续。

## 适用场景

**场景：小型场景切换**
推荐方式：同步加载

**场景：大型场景/需要加载界面**
推荐方式：异步加载

**场景：无缝大世界**
推荐方式：异步加载 + 场景叠加

## 技术地位和意义

SceneChangeMgr 是框架中负责「场景流转」的组件。它简化了场景切换的操作，让开发者可以更专注于场景内容本身。

*场景切换是游戏流程的「关节」，虽然代码不多，但体验好不好，往往就看这些细节。*
